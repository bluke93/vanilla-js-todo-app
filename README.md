# Demo To-Do App with Vanilla JS, HTML, and CSS

This is a simple demo of a to-do app built from scratch using only **Vanilla JavaScript**, **HTML**, and **CSS**. The app mocks a database system by utilizing `localStorage` to store tasks locally.

## Features

- Add, edit, and delete tasks.
- Mark tasks as completed or pending.
- All data is stored in the browser using `localStorage` for persistence across sessions.
  
## Why I Created This Repo

I created this repo to teach some junior developers and introduce them to **JavaScript** and building applications with **Vanilla JS** as a base. This project aims to help them understand fundamental concepts before diving into more complex and advanced JavaScript frameworks and libraries.

## How to Run the App

1. Clone this repository:
   ```
   git clone https://github.com/bluke93/demo-todo-app.git
   ```

2. Open the `index.html` file in your browser to view the app.

## Technologies Used

- **HTML** for the structure
- **CSS** for the styling
- **Vanilla JavaScript** for the functionality
- **localStorage** to persist tasks in the browser
